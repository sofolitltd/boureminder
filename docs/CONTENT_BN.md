# Content & Copy Deck: বউ রিমাইন্ডার

অ্যাপের সব ব্যবহারকারী-দৃশ্যমান লেখা এখানে। কোডে কোনো বাংলা স্ট্রিং হার্ডকোড করা যাবে না।

- অ্যাপের UI টেক্সট → `lib/l10n/app_bn.arb` ও `app_en.arb`
- পুশ নোটিফিকেশন (সার্ভার পাঠায়) → `api/internal/copydeck/` (এই ফাইলের §৩ থেকে)
- বড় তালিকা (প্রম্পট, সরি, শাস্তি, বাজার ডিকশনারি) → `assets/data/*.json`

**ভেরিয়েবল:** `{partner}` = সঙ্গীর ডাকনাম ("ম্যাডাম", "জনাব" বা ইউজারের দেওয়া নাম), `{me}` = নিজের ডাকনাম, `{count}`, `{time}`, `{amount}` ইত্যাদি। সংখ্যা ও সময় ইউজারের সেটিং অনুযায়ী বাংলা বা ইংরেজি অঙ্কে রেন্ডার হবে।

## ১. লেখার নীতি (Voice & Tone)

| করুন | করবেন না |
|---|---|
| বন্ধুর মতো উষ্ণ, হালকা খোঁচা | অপমান, তাচ্ছিল্য, কারো চেহারা বা পরিবার নিয়ে মজা |
| ছোট বাক্য, এক নোটিফিকেশনে এক কথা | লম্বা অনুচ্ছেদ |
| চলিত বাংলা, "আপনি" সম্বোধন | "তুই/তুমি" (ইউজারের সঙ্গীকে নিয়ে লেখা ছাড়া) |
| একটা ইমোজি, শেষে | একাধিক ইমোজির স্তূপ |
| রোল-নিরপেক্ষ কপি `{partner}` দিয়ে | ধরে নেওয়া যে সবসময় স্ত্রীই পাঠান বা স্বামীই ভোলেন |
| এরর মেসেজে সমাধান বলা | দোষারোপ ("আপনি ভুল করেছেন") |
| দলিল সেকশনে কোমল, মজা কম | দলিলে খোঁচা বা ব্যঙ্গ |

হাসি সবসময় **দুজনের সাথে**, কারো **বিরুদ্ধে** নয়। যে কপি পড়ে কেউ সত্যিই কষ্ট পেতে পারেন, সেটা বাদ।

## ৪. ভালোবাসার দলিল: দৈনিক প্রম্পট (৬০টি)

`assets/data/deed_prompts_bn.json` → `[{"id":"p01","text":"..."}]`। একই প্রশ্ন ৬০ দিনের মধ্যে আবার আসবে না।

1. আজ আপনার সঙ্গী এমন কী করেছেন যা আপনার ভালো লেগেছে?

3. আজকের দিনে সঙ্গীর কোন কথাটা মনে রাখার মতো?

5. কোন মুহূর্তে মনে হয়েছিল, "এই মানুষটাকে বিয়ে করে ঠিক করেছি"?
6. সঙ্গীর হাসির কোন ব্যাপারটা আপনার সবচেয়ে প্রিয়?
7. আজ সঙ্গী আপনার জন্য ছোট্ট কোন কাজটা করে দিয়েছেন?
8. সঙ্গীর রান্না বা পছন্দের কোন জিনিসটা আপনার মন ভালো করে দেয়?

10. সঙ্গীর কোন গুণটা আপনি নিজের মধ্যেও চান?

## ৯. এরর মেসেজ (সার্ভারের `code` → বাংলা)

| code | বার্তা |
|---|---|
| `network_offline` | নেট নেই। সংযোগ ফিরলে আবার চেষ্টা করব। |
| `timeout` | সার্ভার একটু ধীর চলছে। আবার চেষ্টা করুন। |
| `server_error` | আমাদের দিকে একটা সমস্যা হয়েছে। একটু পরে চেষ্টা করুন। |
| `unauthenticated` / `invalid_token` | আবার লগইন করতে হবে। |
| `forbidden` | এটা দেখার অনুমতি আপনার নেই। |
| `not_found` | এটা আর খুঁজে পাওয়া যাচ্ছে না। হয়তো মুছে ফেলা হয়েছে। |
| `pair_code_not_found` | এই কোডটা মিলছে না। আবার দেখে লিখুন। |

| `pair_code_used` | এই কোড আগেই ব্যবহার হয়েছে। |

## ১০. মাসিক সংসার রিপোর্ট (Wrapped) টেমপ্লেট

সার্ভার স্লাইড বানায় শুধু তখনই, যখন ডেটা আছে (০ হলে সেই স্লাইড বাদ)।

| key | টেমপ্লেট |
|---|---|
| `intro` | {month}: আপনাদের সংসারের এক মাস 📊 |
| `bazar_done` | এই মাসে {name} {count}টি ফর্দ সম্পন্ন করেছেন। 🛒 |
| `bazar_forgot` | আর {count}টি জিনিস "পাওয়া যায়নি"। সত্যিই পাওয়া যায়নি তো? 🤔 |
| `bazar_fast` | সবচেয়ে দ্রুত বাজার: {minutes} মিনিটে! ⚡ |
| `deeds` | একে অপরকে {count}টি প্রশংসা লিখেছেন। 💌 |
| `cases_top` | সবচেয়ে বেশি মামলা: {category} {emoji} |
| `cases_settle` | আপোষের হার {percent}%। সংসারে শান্তি। 🕊️ |
| `streak` | দলিলের সবচেয়ে লম্বা স্ট্রিক: {days} দিন 🔥 |
| `outro` | পরের মাসে আরও হাসি, আরও কম ভুলে যাওয়া! ❤️ |

শেয়ার ছবির কোণে: "বউ রিমাইন্ডার" লোগো। বাজার খরচ শেয়ার ছবিতে ডিফল্টে থাকে না।
