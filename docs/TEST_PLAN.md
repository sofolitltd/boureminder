## ৩. ইন্টিগ্রেশন ফ্লো (দুই ডিভাইস / দুই টেস্ট ইউজার)

1. **পেয়ারিং:** A কোড বানায় → B কোড দেয় → দুই ডিভাইসে ৩ সেকেন্ডে "সংসার জুড়ে গেল"।
2. **বিশেষ দিন:** A জন্মদিন দেয় → B-র ডিভাইসে রিমাইন্ডার শিডিউল হয়, A-র ডিভাইসে নয়।
3. **ফর্দ:** A ১০টি জিনিসের ফর্দ পাঠায় → B পুশ পায় → B ৫টি টিক দেয় → A লাইভ দেখে → B শেষ করে → A সারাংশ পুশ পায়।
4. **অফলাইন ফর্দ:** B এয়ারপ্লেন মোডে ৮টি টিক → নেট চালু → A-তে সব ৮টি, কোনো ডুপ্লিকেট নেই।
5. **দলিল:** A ৭টি এন্ট্রি লেখে → B শুধু "৭টি চিঠি" দেখে → A "এখনই উপহার" → B রিভিল দেখে → PDF ডাউনলোড।
6. **মামলা:** A মামলা → B সাফাই → A রায় → দুজনেই স্ট্যাম্প দেখে।
