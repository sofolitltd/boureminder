# বউ রিমাইন্ডার (Bou Reminder): প্রজেক্ট ডকুমেন্টেশন

> সংসারের সব জরুরি কথা, সময়মতো।

বাংলাদেশি দম্পতিদের জন্য একটি মজার, উষ্ণ সংসার সহকারী অ্যাপ: বিশেষ দিনের রিমাইন্ডার, বাজারের ফর্দ পাঠানো ও লাইভ ট্র্যাকিং, প্রতিদিনের প্রশংসা জমিয়ে "ভালোবাসার দলিল" PDF উপহার, আর খুনসুটির মামলা।

## টেক স্ট্যাক এক নজরে

```
Flutter 3.47 + Riverpod 3 + Drift (লোকাল-ফার্স্ট)
        │  HTTPS + WebSocket
Go 1.27 API (Fly.io, সিঙ্গাপুর) + River জব
        │
Neon Postgres  +  Neon Object Storage (S3)        Firebase: শুধু Auth + FCM
```
